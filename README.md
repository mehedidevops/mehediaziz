# Mehedi Aziz — Futuristic AI Engineer Portfolio

Next.js, TypeScript, Tailwind CSS, Motion. GitHub Pages project URL: https://mehedidevops.github.io/mehediaziz/

## Local development

```bash
npm install
npm run dev
```

## Deployment

Configure Settings → Pages → Source → GitHub Actions. Every push to main invokes .github/workflows/deploy.yml. Static export uses /mehediaziz as basePath.
